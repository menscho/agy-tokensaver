# Changelog

All notable changes to **agy-tokensaver** (`menscho/agy-tokensaver`) are documented here.

## [Unreleased]

- **Real-session benchmark (`scripts/transcript_replay.py`, `benchmark.py --replay`, `make_benchmark_chart.py`):** replays every recorded tool call of all local IDE + CLI sessions through the real hooks with exact per-turn tokens (transcript or `conversations/*.db`), charges retries, follow-up reads and the plugin's own prompt overhead, and renders `docs/assets/benchmark-chart.svg`.
- **Windows PowerShell compression:** `cmd_hook.pl` / `cmd_hook_core.pl` / `cmd_wrap.pl` wrap noisy PowerShell commands (cmdlet listings, builds, package managers) through a child `powershell.exe` with exact exit codes and raw spill; fixes Git-perl hosts rewriting PowerShell commands into `bash -c`, and the `do`-path bug that kept the core from loading via a Windows path. `AGY_TS_SHELL=off|posix|pwsh`.
- **read_hook.pl:** compaction-verified dedupe window (from the transcript, fallback 16 steps), MD5 fingerprint, missing-range trim for partially covered re-reads, shorter reasons; prose docs up to 46 KB are no longer auto-capped (each cap forced a follow-up read).
- **grep_hook.pl (new):** fixes Windows `grep_search` on a single file (always "No results") via parent dir + `Includes`.
- **Auto-Handoff:** one causal `rollover_policy()` shared by the live tick, HUD threshold and simulator (no oracle), settled-only live firing, learned continuation probability, measured 17k cold start, denser handoff packet (lists edited files), all 30 IDE + CLI sessions visible to the HUD (db token fallback), background-task id regex fix.
- **Headroom-inspired stdlib compressors (`scripts/cmd_wrap.pl`):** lossless JSON `[N]{cols}` CSV+schema compaction (with 1-level nested flattening, `>256 B` blob offload, and error/outlier-preserving `SmartCrusher` sampling past 9.9 KB), dense machine-generated line elision, repeated multi-line block folding, large-diff `±2` context trimming, Windows-safe grep path hoisting, and SSH remote grep path hoisting (`+45%` more SSH tokens removed on real-session replay).
- **`@plexer/cli`-inspired lifecycle guards (`scripts/post_edit_hook.pl`, `cmd_hook_core.pl`, `read_hook.pl`, `ts_inspect.py`):** `PostToolUse` edit tracker (`editseq` bump + immediate `read_hook.pl` entry invalidation), duplicate search / unchanged `git diff` dedup with a 1-retry escape hatch, `WaitMsBeforeAsync` floor bump (`5000 ms`) on fast read-only queries, `initialNumSteps` drop compaction reset in `read_hook.pl`, and stdlib AST/regex `ts_inspect.py outline`.
- **Prompt overhead 906 → 433 tok/turn:** ~0.7 KB rules (new: no file writes via `run_command`, no `ArtifactMetadata` outside the brain dir), 3 scouts instead of 5 (`scout` replaces `fast-explorer`/`triage-scout`/`web-scout`), short skill descriptions.
- **Opt-in high-leverage modes (toggleable in the HUD & benchmarked separately via `benchmark.py --modes`):**
  - **Compact Reads (`compact_reads` / `AGY_TS_COMPACT_READS=1`):** tighter unbounded caps (120L code / 140L docs / 80L data; bounded slices untouched) — cuts +48% more real tool tokens (`216k → 322k` on 66 sessions).
  - **Concise Output (`concise_output`, Caveman-lite / CoD-SWE):** strips pleasantries, preambles, and pre/post-tool chatter to cut `6×`-weighted output tokens while keeping code, diffs, paths, and errors verbatim.
- **Zero-loss additions:** POSIX `ffmpeg` banner/progress filtering, read-only `python3 -c` inspection wrapping (`>=80 B`), JSON/table compaction inside `compress_logs`, and pre-drop idle cache-rebuild cost warnings in `post_invocation_alerts.pl`.
- **297 assertions across 7 test suites** (`run_tests.sh`, `test_cmd_windows.sh`, `test_read.sh`, `test_rollover.sh`, `test_rules.sh`, `test_tools.sh`, `test_headroom_plexer.sh`) verified in 3-OS CI.

## [1.0.0] — Initial Open-Source Release

- **Fail-Open Perl Hooks (`PreToolUse` / `PostInvocation` / `Stop`):**
  - `cmd_hook.pl`, `cmd_hook_core.pl`, `cmd_wrap.pl`: Quote-aware shell classifier supporting `&&`/`;`/newline chains of known segments, `|| true`, safe read-only stdout filter pipelines (`| grep/rg/sort/uniq/awk/sed/jq`), multi-directory `ls -la`, and test/build/audit Python scripts. Skips redirects, heredocs, `tee`, `-f`/`--follow`, PowerShell syntax, and native `MSWin32` PowerShell shells. Preserves exit/signal codes and TTY prompts, pins error/warning/traceback lines, omits lockfile/vendor-bundle diffs, and saves raw unmodified output to the OS temp directory (`agy-tokensaver-<uid>`).
  - `read_hook.pl`: Recognizes Unix `/`, Windows `C:\`, and UNC paths; blocks binaries, SQLite DBs, 25+ lockfiles, sourcemaps, minified bundles, and unchanged exact/superset-covered re-reads (`>4 KB`, `≤16` steps, same compaction epoch). Only records line ranges guaranteed below `read_file`'s 46,080 B / 800-line truncation ceiling and logs signed slice-sized savings minus denial/overwrite overhead. Auto-caps unbounded data files (`>8 KB`) and large source files (`>16 KB`).
  - `write_hook.pl`, `find_hook.pl`, `swarm_hook.pl`, `post_invocation_alerts.pl`, `stop_telemetry.pl`.
- **Native Full-Page HUD (`mcp_app/`):** Global Antigravity MCP App (`agy-tokensaver`) with `Overview`, `Archive`, and `Updates` tabs; internal RPC tools use `visibility: ["app"]`.
- **Archive & Optional Rollover (`scripts/handoff_pack.py`, `mcp_app/core.py`):** Defaults to `Archive Only` (no automatic new chats; `Smart Auto` and `Off` selectable in the HUD). Targets the exact conversation ID being packed, extracts workspace git state + recent commits + touched files + last goal/assistant summary into a compact continuation prompt, and works cross-platform on Unix and Windows.
- **Tagged, SHA-256 Verified Installer & Updater (`install.py`, `Updates` tab):** Installs and updates only from tagged GitHub Releases verified against `SHA256SUMS.txt`, pins the active Python path in `mcp_config.json` on native Windows, and preserves `~/.gemini/antigravity/plugin_data/token-saver/`.
- **Reproducible Benchmarks & 3-OS CI (`scripts/benchmark.py`, `.github/workflows/test.yml`):** Deterministic 6-step Before/After hook benchmark (`--demo`, routed through `cmd_hook.pl`'s actual decisions), local transcript counterfactual replay (`--transcripts`, signed per-session median/mean/regression count + total quota-weighted savings with `+8k` re-read tax per rollover), and 168 regression assertions running in GitHub Actions on Ubuntu, macOS, and Windows.
- **5 Flash/Flash-Lite Scouts & 3 Isolated Workflows:** `lite-sifter`, `fast-explorer`, `triage-scout`, `vision-scout`, `web-scout`, `/lean-workflow`, `/handoff`, `/swarm-prep`, `/token-stats`, and `/context-audit`.
