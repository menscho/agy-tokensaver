# Code of Conduct

We are committed to providing a welcoming, respectful, and harassment-free experience for everyone contributing to or using `agy-tokensaver`.

## Expected Behavior

- Be constructive, direct, and respectful in code reviews, issues, and discussions.
- Focus critique on technical details, measurements, and reproducibility rather than individuals.
- Respect maintainers' time by including reproduction steps and minimal inputs when reporting bugs.

## Enforcement

Unacceptable behavior (harassment, personal attacks, trolling, or publishing private information) may be reported to the repository maintainer via GitHub and may result in removal of comments or blocking from the repository.
