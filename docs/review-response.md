## 3. What Could Not Be Run Headlessly

- **Live end-to-end LLM pass rate (`eval/results/live_eval.json`):** `agy` CLI is not installed on this machine (`which agy` empty) and full agent solves require live Antigravity IDE/LLM inference. Both `--driver agy` and `--driver manual` are wired and unit-tested, and `README.md` states `"live pass-rate: not yet measured"`.
- **Local static linter execution:** `ruff`, `mypy`, `perlcritic`, `shellcheck`, and `coverage` Python packages are not installed in this Linux container, so `perl -Iscripts/lib -c`, `python3 -m py_compile`, and `bash tests/run_all.sh` ran locally while GitHub Actions `Lint, Types & Coverage` runs full static checks on push.

## 4. Remaining Known Weaknesses (Stated Honestly)

1. **Small default savings (`-0.7%` avg, `+0.1%` median):** Across real coding sessions, plain-editing turns dominate and carry no large command dumps, while `rules/AGENTS.md` + skill descriptions always cost `190 tok/turn`. Default lossless mode pays off on test/log-heavy workflows, not short edits.
2. **Auto-Handoff has a real context tradeoff:** The largest measured savings (`-19.2%` to `-19.7%` avg) come from starting fresh chats, which drops verbatim earlier turns beyond the compact handoff summary.
3. **Unmeasured LLM quality delta for Mode 2 options:** Until a maintainer runs `eval/runner.py --driver manual` or `--driver agy` across `N >= 3` trials per task, task solve-rate equivalence for `Compact Reads`, `Concise Output`, and `Auto-Handoff` remains unverified end-to-end.
4. **Native Win32 Perl (`MSWin32`) POSIX pass-through:** Strawberry Perl has no POSIX `/bin/bash`, so commands explicitly forced into `AGY_TS_SHELL=posix` or Unix `/...` working directories pass through `{"decision":"allow"}` unmodified (Windows PowerShell `C:\...` commands compress normally on both Strawberry and Git-Bash Perl).
5. **Tag protection ruleset requires GitHub admin UI:** Automated CI enforces tag-vs-version parity, but immutable `refs/tags/v*` rulesets (`SECURITY.md`) require maintainer configuration in repository settings.
